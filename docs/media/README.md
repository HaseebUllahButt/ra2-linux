# Gameplay recordings

These clips show the final native Linux build on a private Xvfb display. Each clip uses H.264 video and has no audio track.

| Clip | Duration | Content |
| --- | ---: | --- |
| [Skirmish](skirmish.mp4) | 58 seconds | Deploy a construction yard, place a power plant, and send troops into battle in Urban Rush. |
| [Campaign](campaign.mp4) | 49 seconds | Start Chrono Defense and see an in-game radar movie. |
| [Menus](menus.mp4) | 38 seconds | Open the main menu, single-player screen, skirmish setup, and options. |

The skirmish and campaign clips cut between moments in the same game. Gameplay plays at its captured speed. The [skirmish GIF](skirmish.gif) and [campaign still](campaign-radar.png) come from those clips.
